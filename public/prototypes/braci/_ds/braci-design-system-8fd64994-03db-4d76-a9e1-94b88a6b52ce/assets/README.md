All art here was extracted from the three brand images the client supplied. Nothing was drawn,
redrawn or generated.

| File | Source | Notes |
|---|---|---|
| `logo-primary.png` | "Font and Logo" sheet / pasted logo PNG | Flame + slice + brush wordmark. Footer lockup. Upscaled 3× from a ~190px source. |
| `logo-slice.png` | pasted secondary-logo PNG | Slice only. Header lockup. Upscaled 4× from a 110×145 source. |
| `doodle-pasta.png` | "Doodles" sheet | Cropped, white knocked out to alpha. Cropped, white knocked out to alpha with a hard curve and the stroke re-saturated to #FF610E. **Source was ~32px** — do not use above ~72px. |
| `doodle-cake.png` | "Doodles" sheet | As above. |
| `doodle-drink.png` | "Doodles" sheet | As above. |
| `doodle-pizza.png` | "Doodles" sheet | As above. |
