One-line: icon-only control for chrome actions (close, back, cart, share) — always pass `label`.

```jsx
<IconButton icon={<i className="ph ph-shopping-bag" />} label="Cart" variant="onOrange" />
<IconButton icon={<i className="ph ph-x" />} label="Close" size="sm" />
```

Variants: plain (transparent, orange-tint hover), outline, solid (ember), onOrange (for the orange header band).
